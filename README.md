## 🔄 My Work Process

```text
Step 1 — 👂 Listen & Understand
          Real conversations, not forms. I ask about goals, audience, and success metrics.

Step 2 — 📐 Plan & Design
          Structure mapping, wireframes, right tool selection (React / WordPress / custom code)

Step 3 — 🏗️ Build & Refine
          Code → Design → Test → Share progress early → Iterate based on your feedback

Step 4 — 🚀 Launch & Support
          Go live → Train you → Fix hiccups → Ongoing support
```
